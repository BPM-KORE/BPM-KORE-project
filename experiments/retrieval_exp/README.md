# 검색 재현율 탐색 (CPU, dev 20문항): 문서 확장과 후보 수

작성일 2026-11-04. dev 탐색 결과이며, 새 문항에서 재확인 필요하다. 이 문서의 어떤 수치도 개선의 확정 근거가 아니다.

## 1. 무엇을 했나
- 문서 쪽만 바꾸고 질의는 건드리지 않았다. 시행령 행 본문에서 「법」 제N조 / 법 제N조(의M) 참조를 정규식으로 찾고, 같은 법(또는 「」 안에 적힌 법)의 조문 제목을 지식 776행에서 찾아 시행령 행 텍스트 뒤에 덧붙인 뒤 BM25(`BM25Retriever` 기본값, `ngram_stem`)를 다시 만들었다. 지식 파일은 읽기만 했고 원본은 그대로다.
- 변형: D1 인용된 법 조문 제목만 / D2 법명+조번호+제목 / D3 D1을 가장 많이 인용된 조문 1개로 제한 / D4 D2를 1개로 제한 / D5 가장 많이 인용된 조문 1개의 본문 전체.
- 후보 수: 순위는 그대로 두고 상위 k를 10, 20, 30, 50으로 늘렸을 때 정답 근거가 후보에 드는 비율.
- 재현율 정의는 `kore/stats.py`의 후보 재현율과 같다. 문항별 (후보 ∩ 정답) / 정답 수를 문항 평균(macro). 근거 44개 전체 합산(micro)도 병기했다. 부트스트랩은 문항 단위 복원추출 5000회, seed 0, 95% 구간.
- 시행령 행 313개 중 253개에서 인용을 찾았고 조문 사전은 452개다. 정답 근거 44개 중 시행령이면서 인용을 찾은 것은 17개이고, 그중 6개가 기준에서 상위 10 밖이다.
- test 분할은 열지 않았다. 질문 파일의 split 값이 dev뿐임을 코드에서 assert로 확인한다. kore/, data/, team/ 은 수정하지 않았다. 커밋하지 않았다.

## 2. 명령
```
python3 -I experiments/retrieval_exp/run_exp.py     # 출력은 같은 폴더 result.txt 에도 저장된다
```
기준선 재현: 후보 10에서 정답 27/44, 후보 밖 17개로 retrieval_diag 보고서와 같다.

## 4. 해석
- 판정 기준(추정 기준): dev에서 상위 10 안 정답 근거 순증 5개 이상이면 개선 후보로 '탐색 통과'. 이 기준에 도달한 변형은 없다. 최대는 D5의 +3(상위 10), +3(상위 30)이다.
- D1~D4(제목·법명 덧붙임)는 상위 10 순증이 0이다. 순위가 몇 칸씩 움직이지만 대부분 10위 밖에서의 이동이라 후보 판정이 바뀌지 않았다. R@10 차이 구간이 [0, 0]이다. 이 변형은 효과를 구분할 수 없다.
- D5는 R@10 macro 0.596 → 0.658이지만 구간이 [0.000, +0.138]로 0에서 시작한다. 순위 상승 13개, 하락 24개로, 시행령 정답 일부는 크게 올라가고(예: Q04의 law_pipa_decree_022 116 → 5, Q05 decree_025 46 → 29) 같은 문항의 본법 정답이 밀린다(예: Q02 law_pipa_031 72 → 103, Q10 law_pipa_073 49 → 74). 본법 본문이 시행령 행에 복제되어 본법 조문과 경쟁하는 것으로 보이며, 이 원인은 이 실행으로 검증하지 않았다.
- 5개 변형 중 가장 좋아 보이는 것을 dev에서 고른 셈이라 D5의 +3도 선택 편향을 안고 있다.
- 후보 수만 늘리면 정답이 후보에 드는 개수는 27(k=10) → 33(k=20) → 35(k=30) → 38(k=50)이다. macro로 0.596 → 0.725 → 0.800 → 0.858. 순위를 바꾸지 않으므로 이 증가는 선택기가 고를 후보의 상한이 늘어난 것이다. 선택기가 그 후보에서 정답을 골라내는지, 후보가 늘어 방해 문서가 섞이는 비용은 어떤지는 재지 않았다. 20문항에서 근거 1개는 R@10 기준 약 0.023이다.
- 정답 근거 17개가 10위 밖인 원인은 retrieval_diag 기준으로 어휘 차이가 12개이고, 이 방식(시행령→본법 제목 덧붙임)이 겨냥하는 것은 본법·시행령 분리로 보이는 일부뿐이다. 문서 확장이 병목 대부분을 못 건드린다는 점이 0 순증과 일치한다.

## 5. 한계
- 20문항은 이미 여러 번 들여다본 세트라 과적합 위험이 크다. dev 탐색 결과이며 새 문항에서 재확인 필요하다.
- 참조 정규식은 사전에 없는 조문, 「」 밖의 다른 법 인용, 같은 법 같은 표현은 버린다. 인용 추출의 정확도는 사람이 검수하지 않았다(부록 예를 눈으로 훑은 정도다).
- 시행령 313행 중 인용이 없는 행(60개)은 확장되지 않았다.
- 재현율은 정답 id 적중뿐이며 답변 품질이 아니다. 후보 수 증가와 확장이 선택기·생성 결과에 주는 영향은 측정하지 않았다.
- 부트스트랩은 문항 20개를 단위로 했고 동점·고정 시드 한 번이다.
