# 평가 체계 정상화 v2 (20문항, 진단용)

상태: **AI 초안 — 사람 승인 대기.** 공식 평가 세트가 아니다. `data/`는 건드리지 않았다. 20문항은 모두 dev 분할이고 진단용이다.

## 무엇을 했나
- C C안(`team/C_전달_2026-11-01/A_검증/evaluation_questions_20_계약형식.csv`)에서 질문, 근거 ID, 난이도, 분할은 그대로 두고 `reference_answer`와 `rubric`만 다시 썼다.
- 근거 조문 원문(`team/provisional/law/knowledge.csv`)과 20문항을 하나씩 대조해 사실을 확인했다.
- 재생성: `python experiments/eval_normalization/build_v2.py`, 검증: `python experiments/eval_normalization/check_v2.py`.

## 왜 고쳤나
`kore.evaluation.rubric_score`는 NFKC·소문자 부분문자열 일치만 본다(형태소 분석 없음). 기존 루브릭은 "위탁 업무·목적·범위 문서화" 같은 설명문이라 정답 문장도 거의 걸리지 않았다.
기존 참조답 자기채점 평균은 **0.250**(10문항이 0.00)이었다. 이 상태로는 `gold_context`가 낮게 나와도 모델 탓인지 채점 탓인지 가를 수 없다.

## 사실 수정 (근거 원문과 대조)
- Q11: 통지(시행령 제39조)와 신고(시행령 제40조) 모두 **72시간**인데 기존 참조답에 없었다. 신고 대상 조건(1천명 이상, 민감·고유식별정보, 외부 불법 접근)도 넣었다. 개인정보법 시행령 신고 예외(회수·삭제로 침해 가능성이 현저히 낮아진 경우)는 질문 범위 밖이라 뺐다.
- Q15: 기존 문장은 "문서 또는 요건에 따라 구술"로 흐렸다. 시행령 제8조는 **문서가 원칙, 기관이 필요하다고 인정하거나 제3자가 원하면 말로**다. 3일은 정보공개법 제21조①.
- Q13: 10일 + 10일 범위 연장 + 문서 통지(법 제11조), 연장 사유 예시는 시행령 제7조.
- Q16: 이의신청은 결정 통지일 또는 청구 후 20일 경과일부터 30일 이내, 행정심판은 이의신청을 거치지 않아도 청구 가능(법 제19조②)으로 구체화했다.
- Q03: 법 제20조① 요구 시 통지에 더해 시행령 제15조의2의 규모 기준 처리자(3개월 이내 통지)를 넣었다. 규모 기준의 세부는 원문 일부만 확인했다.
- Q06: 법 제24조의2③(회원 가입 때 주민번호 없이 가입할 방법 제공)을 추가했다. 시행령의 암호화 적용 시기는 이미 지난 일정이라 뺐다.
- Q18: 시행령 제17조①의 평가 기준 4가지를 그대로 썼다. 시정조치는 같은 조 ②4호(평가 계획에 포함되는 시정조치)까지 확인했고, 그 뒤 ④항의 후속 조치 내용은 원문이 잘려 확인하지 못했다.
- Q12·Q14·Q17·Q19·Q20: 조문과 일치함을 확인하고 필요한 사실만 보강했다.

## 한계 (현실적으로)
- 키워드 일치라 **부정문을 못 가른다**: Q13 반례("연장은 허용되지 않는다")가 "연장"에 걸려 0.25가 나왔다. 키워드를 모두 나열한 답은 1.0이 나온다. 그래서 `rubric_score` 단독은 근사치이고, 실험 결과를 말할 때는 사람 채점(`kore blind`) 표본을 같이 본다.
- 참조답이 계약의 "한 문장"보다 길다. `labeling`의 로그확률 라벨은 길수록 노이즈가 커질 수 있다. 쓰기 전에 짧은 판본이 필요한지 본다.
- 사실 확인은 조문 원문 대조까지다. 법률 해석의 옳고 그름을 전문가가 본 것은 아니다. 사람 검토 전에는 공식 세트로 쓰지 않는다.
- 20문항은 통계적으로 작은 개선을 가려내기 어렵다(결정기록 4절). 이 세트는 진단용이다.
