# KORE B 선행연구 검증 결과

정리일: 2026-10-30. 대상: arXiv 2507.04480 및 RepoShapley.

## 실제 완료
- 2편 논문에 관하여 6가지 비교 질문 × 2편 = 12행을 `overlap_B.csv`로 작성하고 절·표 근거 위치 기록.
- 지용(B)은 공식 원문에서 **5곳**을 직접 확인했다고 보고: 첫 논문 Abstract, §3.3, §3.4.1; RepoShapley Abstract, Table 2.
- **첫 논문 §4.2 Table 1의 수치**는 이전에 확인을 요청했지만 지용이 확인 완료라고 답한 기록은 없음. 직접 검증 **미완료**로 기록.
- 논문 전체 정독을 주장하지 않음. `read_scope=method`는 선정된 방법·실험 구간에 한정된 검토를 뜻하며 논문 전체를 읽었다는 뜻이 아님.

## 선행연구 중복 및 범위
- 첫 논문은 RAG 문서별 기여도와 문서 관계를 조사.
- RepoShapley는 여러 코드 문맥의 기여도와 조합을 이용해 유지/삭제 선택을 학습.
- 따라서 '자료 기여도를 측정한다' 또는 '기여도로 선택을 개선한다'는 일반 개념 자체는 선행 사례가 있음.
- **기존에 확정된 KORE의 정확한 가설·방법과의 항목별 겹침은 아직 분석 완료가 아님.** 신규 연구 주제 제안이나 방향 변경을 한 것이 아님.

## 남은 일
1. 첫 논문의 §4.2 Table 1 대표 수치 사용자 직접 검증(필요할 경우).
2. 각 논문의 기여도 정의 및 본문 근거 중 현재 사용자 미확인 부분 검토.
3. 서준(A)의 **최종 확정 KORE 가설·실험 설계**와 일대일 중복성 대조 후 승인.
4. 이 보고서와 `overlap_B.csv`를 서준에게 전달.
