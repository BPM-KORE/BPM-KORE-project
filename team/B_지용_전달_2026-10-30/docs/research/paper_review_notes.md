# 선행연구 확인 메모 (2026-10-30)
- 문서 기여도 추정, 문서 상호작용 분석, 이를 이용한 선택 정책 학습은 선행연구가 존재.
- KORE의 실제 확정 설계와의 세부 중복 여부는 서준(A)의 계획 문서와 나란히 대조해야 함.
- `overlap_B.csv`는 12개 조사 항목의 AI 작성 조사자료. `read_scope=method`는 전체 논문 정독을 의미하지 않음.
- 사용자 직접 확인 5개 지점은 `논문_직접확인_로그.csv`를 참고. 첫 번째 논문의 Table 1 결과 수치는 사용자 직접 확인 대기.
- 논문 공식 원문: https://arxiv.org/html/2507.04480 ; https://aclanthology.org/2026.findings-acl.505/
