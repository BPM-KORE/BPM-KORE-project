# KORE B 라이선스 조사 및 직접 확인 기록

작성·정리: 2026-10-30. **사람 확인의 근거는 이 대화에서 지용(B)이 직접 확인했다고 보고한 내용**이다. AI가 직접 확인한 출처와 구분한다.

## 1. 저작권법 제7조
- 공식 주소: https://www.law.go.kr/lsLinkProc.do?joNo=000700&lsClsCd=L&lsNm=저작권법&mode=11
- 지용 직접 확인: **2026-10-30 / 확인 보고**
- 이용 조건: 제7조 제1호는 헌법·법률·명령·조례·규칙 등을 저작권법상 보호받지 못하는 저작물로 규정.
- KORE 사용 판단: 공식 법령 조문을 실험용 텍스트로 정리·분할하는 범위는 원칙적으로 가능하다고 판단.
- 미확정: 민간 해설·별도 이미지·제3자 저작물의 권리, 법령별 시행일과 내용의 정확성.

## 2. 국가법령정보센터 이용정책
- 공식 주소: https://www.law.go.kr/lawPetitionForm.do?menuId=13&subMenuId=79
- 지용 직접 확인: **2026-10-30 / 자유이용 조건과 제3자 권리 예외를 확인했다고 보고**
- 이용 조건: 저작권법 제7조 대상 및 법제처가 권리를 보유한 자료의 자유이용 안내. 다만 제3자 권리, 법령·서비스별 예외를 준수.
- KORE 사용 판단: 법령 원문을 연구 입력자료로 사용할 수 있다는 잠정 판단.
- 미확정: 특정 첨부자료의 권리와 API·대량수집 규정, 데이터 판본의 일치 여부.

## 3. 한국어 위키백과
- 공식 주소: https://ko.wikipedia.org/wiki/위키백과:저작권
- 약관: https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use/ko
- 지용 직접 확인: **2026-10-30 / CC BY-SA 4.0, 저작자표시, 동일조건변경허락을 확인했다고 보고**
- 이용 조건: 본문 일반적으로 CC BY-SA 4.0. 재사용 시 저작자표시, 개작물을 공유하면 동일조건 조건 적용 가능. 개별 파일은 별도 조건 가능.
- KORE 사용 판단: 향후 별도 비법률 데이터로 채택할 때 조건을 준수해야 하며 **현재 법령 10종 CSV에는 위키백과 본문이 없음**.
- 미확정: 특정 문서·이미지의 라이선스, 파생 데이터 공개 시 의무 범위.

## 4. 공공누리 제1유형 기관 문서
- 사용자가 안내받은 개별 자료 링크: https://www.kogl.or.kr/recommend/recommendDivView.do?division=doc&recommendIdx=98321
- 일반 이용 안내: https://www.kogl.or.kr/info/publicGuide.do
- 지용 직접 확인: **2026-10-30 / 개별 기관 문서의 제1유형 표시를 봤다고 답했으며, 출처표시·변경·상업적 이용 조건이 보인 화면을 제시함**.
- 이용 조건: 제1유형은 **출처표시**, 상업적·비상업적 이용 및 2차 저작물 작성 가능.
- KORE 사용 판단: 제1유형으로 표시된 해당 기관 문서의 해당 권리 범위에서 이용 가능. 이 기관 문서는 법률 데이터에는 포함하지 않음.
- **추가 확인 필요**: 앞선 AI 초안에 서로 다른 자료명과 링크(`98373`, `98321`)가 혼재했음. 사용자가 실제 확인한 개별 자료의 **정확한 제목·제공기관·첨부파일 적용범위**는 공식 페이지/화면에서 다시 대조 필요. 제목은 확정 기재하지 않음.
