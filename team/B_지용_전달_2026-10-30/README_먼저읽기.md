## 원본과 수정 제안본 혼동 금지
- `data/`는 **777행 기존 원본**. 그대로 보존.
- `suggested/data/`는 **776행 수정 제안본**. 2027년 시행 표시 행 1개를 임시 제외하고 문자열 정리. **승인 전 원본 덮어쓰기 금지**.
- 한 버전의 `knowledge.csv`는 반드시 **같은 버전의** `source_log.csv`와 쌍으로 사용.

## 나머지 폴더
- `raw/`: 사용자 HWP에서 추출한 TXT 10개 원문 + 10개 단일 판본.
- `original_HWP/`: 사용자가 업로드한 법률 HWP 10개. 엉뚱하게 첨부한 사주팔자 PDF는 **포함하지 않음**.
- `docs/research/`: 라이선스·논문·외부 데이터셋·조문 표본·검증 결과.
- `tools/`: 데이터 생성·검증 관련 파이썬 도구 (프로젝트 코드와 함께 사용).
- `서준에게_보낼_메시지.txt`: 붙여 넣어 전달할 구글 챗 메시지.

## 반드시 알고 있어야 할 제한
1. 777행 HWP↔CSV 일치는 편집주석/공백 정규화 기준이며 **공식 사이트 777행 전수 대조는 아님**.
2. `source_log.csv`는 전부 `license_checked=no`, `verified_by` 공란. 4개 이용조건을 확인했다고 777행이 자동 확인된 것은 아님.
3. 첫 논문 Table 1 사용자 검증은 아직 보고되지 않음. 다른 핵심 5곳 직접 확인.
4. A의 최신 확정 연구 설계를 받지 못해 논문과의 완전한 중복성 평가 및 연구 효능 입증은 미완료.
5. 원래 `KORE_자료묶음/00_먼저읽기.md`는 저장소가 없으면 **구글 챗으로 A에게 보내도록** 안내함. GitHub 직접 업로드는 필수 아님.

목록과 승인 요청은 `B_남은작업.md`를 참조해 줘.
