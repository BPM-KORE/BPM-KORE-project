# KORE C 이번 주 1차 과제 산출물

이 묶음은 C의 이번 주 1차 과제용 작업물이다.

- `docs/rubric_scale.md`: KORE 기존 자동 루브릭 구현 설명
- `docs/research/overlap_C.csv`: ContextCite 비교 분석
- `docs/research/core_alignment_check.md`: 설명과 현재 코어 구현 대조 기록
- `data/evaluation_questions_20_provisional.csv`: 기존 20개 질문을 CSV 스키마로 정리한 임시 세트
- `docs/research/question_review_20.md`: 문장·루브릭 검토와 미검증 항목 기록

중요:
- 사용자의 요청에 따라 기존 20개를 원래 공식 7개 과제의 임시 대체 세트로 처리했다.
- 법률자료는 베타테스트용이다. 이 20개를 법률 분야의 최종 승인 평가셋으로 일반화하지 않는다.
- `dev`는 임시 지정이다. 최종 split은 A와 프로토콜에 따라 확정해야 한다.
- 원본 `knowledge.csv` 및 법령 본문을 대조하지 못했으므로 근거 ID의 실재·내용 일치와 법령 최신성은 검증 완료로 표시하지 않았다.
- KORE 코드 변경 및 GitHub 업로드/커밋은 수행하지 않았다.
