# results/

실험 결과 폴더다. 실행마다 하위 폴더를 하나 만든다(예: `results/2026-10-30_baseline/`).

폴더 안에 남는 파일:

| 파일 | 내용 |
|---|---|
| `run_log.jsonl` | (질문, 조건) 한 쌍마다 한 줄. 후보·선택 id, 지표, 답변, 지연시간 |
| `results.csv` | 조건×분할별 평균과 recall·rubric의 95% 부트스트랩 구간 |
| `comparisons.csv` | 각 조건을 `vanilla_rag`와 같은 질문끼리 짝지은 차이와 구간 |
| `env.json` | seed, 설정 해시, 데이터 해시, 생성기, 파이썬·플랫폼, git 커밋, 시각 |

규칙:

- 결과 폴더에는 항상 산출 보고서(`REPORT.md`)를 함께 둔다. 숫자만 남기지 않는다.
- `--final-test`로 돌린 결과는 최종 평가 한 번뿐이다. 그 결과를 보고 알고리즘을 고치지 않는다.
- 큰 파일(모델 가중치, 임베딩 배열)은 저장소에 넣지 않는다. Drive 경로만 `env.json`이나 보고서에 적는다.
- 샘플 데이터(`data/sample_*.csv`)로 돌린 결과는 배관 점검용이다. 연구 결과로 인용하지 않는다.
